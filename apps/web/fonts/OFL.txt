Modified Versions: converted to WOFF2; the RSP, EMC, Gudea and LAK fonts are
subset to the code points the Noto font does not cover (build.py); the other
fonts are subset to their script's Unicode blocks, variable fonts are pinned to
normal width, and UniHieroglyphica is split into chunks by code point
(build_scripts.py). Because "Hieroglyphica" is a Reserved Font Name, the
modified UniHieroglyphica files are renamed "Sumer Egyptian Hieroglyphs" in
their name tables.
